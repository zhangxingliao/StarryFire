# StarryFire 主题系统设计

> 状态：**已实现**。运行时持有两套主题（深色 `Dark Nebula` / 浅色 `Crystal`），可切换且选择持久化于配置。
> 本文档描述调色板、字体尺度、预置 `lv_style_t` 样式表以及 LVGL `lv_theme_t` 集成方案。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 统一视觉风格 | 所有系统组件和 App 使用同一套颜色、字体、圆角、间距 |
| 运行时切换 | `sf_theme_set_active()` 即时切换主题并全局刷新，选择保存到 `sf_config` |
| 最小内存开销 | 预置 `lv_style_t` 对象复用，避免每控件重复调用 `lv_obj_set_style_*` |
| 渐进迁移 | 现有代码仍可局部覆盖样式，主题只提供「默认」基线 |
| LVGL 原生集成 | 使用 `lv_theme_t` 机制，控件创建时自动继承主题样式 |

## 3. 字体尺度

| 级别 | 字号 | LVGL 字体 | 用途 |
|------|------|-----------|------|
| xs | 12 | `lv_font_montserrat_12` | App 名称、小标签 |
| sm | 14 | `lv_font_montserrat_14` | 时钟、列表副文本、正文 |
| md | 16 | `lv_font_montserrat_16` | 列表项标题、按钮文本 |
| lg | 20 | `lv_font_montserrat_20` | 页面标题、大字读数 |
| xl | 28 | `lv_font_montserrat_28` | App 图标（Symbol 字体） |
| xxl | 48 | `lv_font_montserrat_48` | 大数字/启动画面（预留） |

**Kconfig 保证**（`boards/<name>/sdkconfig.defaults` 已启用）：
```
CONFIG_LV_FONT_MONTSERRAT_16=y
CONFIG_LV_FONT_MONTSERRAT_20=y
CONFIG_LV_FONT_MONTSERRAT_48=y
```
字体 `12`、`14`、`28` 是 LVGL 默认内置，无需显式 Kconfig。

**字体宏**：
```c
#define SF_FONT_XS  &lv_font_montserrat_12
#define SF_FONT_SM  &lv_font_montserrat_14
#define SF_FONT_MD  &lv_font_montserrat_16
#define SF_FONT_LG  &lv_font_montserrat_20
#define SF_FONT_XL  &lv_font_montserrat_28
#define SF_FONT_XXL &lv_font_montserrat_48
```

## 4. 圆角、间距与 UI 缩放

| 令牌 | 值 | 用途 |
|------|-----|------|
| `SF_RADIUS_NONE` | 0 | 全铺容器、bars |
| `SF_RADIUS_SM` | 4 | 小圆角（输入框内） |
| `SF_RADIUS_MD` | 8 | 普通卡片 |
| `SF_RADIUS_LG` | 12 | App 图标按钮 |
| `SF_RADIUS_FULL` | `LV_RADIUS_CIRCLE` | 圆形（Wi-Fi 点等） |
| `SF_PAD_SM` | 4 | 紧凑内边距 |
| `SF_PAD_MD` | 8 | 普通内边距 |
| `SF_PAD_LG` | 12 | 宽松内边距 |
| `SF_GAP_SM` | 4 | 紧凑间隔 |
| `SF_GAP_MD` | 8 | 普通间隔 |

**UI 缩放单位 `SF_UI()`**（`sf_theme.h`）——适配不同尺寸 LCD：

```c
/* 以短边 240px 为基准：SF_UI(px) 在 240 短边上恒等变换，其他分辨率按短边比例缩放 */
#define SF_UI_SHORT_SIDE \
    (CONFIG_SF_HAL_DISPLAY_WIDTH < CONFIG_SF_HAL_DISPLAY_HEIGHT ? \
     CONFIG_SF_HAL_DISPLAY_WIDTH : CONFIG_SF_HAL_DISPLAY_HEIGHT)
#define SF_UI(px) (((px) * SF_UI_SHORT_SIDE + 120) / 240)
```

用法：`lv_obj_set_size(obj, SF_UI(56), SF_UI(56));` 用于可缩放尺寸（图标/条高/间距）；
**1px 分隔线、边框、字号与圆角常量不使用 `SF_UI()`**。当前各 UI 已全面应用。

## 6. LVGL `lv_theme_t` 集成 【已实现】

### 6.1 实现方式

`sf_theme.c` 创建自定义 `lv_theme_t`，注册 `apply_cb`。实际实现中 apply_cb 仅对通用
`lv_obj_class` 施加 `SF_STYLE_TRANSP`，其余默认样式由各 UI 显式通过 `sf_theme_get_style()`
获取后 `lv_obj_add_style()` 添加：

```c
static void theme_apply_cb(lv_theme_t *th, lv_obj_t *obj)
{
    (void)th;
    if (lv_obj_check_type(obj, &lv_obj_class)) {
        lv_obj_add_style(obj, &s_styles[SF_STYLE_TRANSP], 0);
    }
}
```

### 6.2 初始化流程 【已实现】

```c
esp_err_t sf_theme_init(void)
{
    lv_disp_t *disp = lv_disp_get_default();
    // 1. init_theme_palettes() 初始化 NEBULA + CRYSTAL 两套调色板
    // 2. 从 sf_config_get_theme() 读取持久化主题并设为 active
    // 3. init_styles(active) 初始化所有预置 lv_style_t
    // 4. lv_theme_create() + lv_theme_set_parent + set_apply_cb + lv_disp_set_theme
    return ESP_OK;
}
```

在 `sf_gui_init()` 中调用（任何 UI 控件创建之前）：`ESP_ERROR_CHECK(sf_theme_init());`

### 6.3 运行时切换 【已实现】

```c
const sf_theme_t *sf_theme_get_active(void);       /* 当前激活调色板 */
esp_err_t sf_theme_set_active(sf_theme_id_t id);   /* 切换主题 */
const lv_style_t *sf_theme_get_style(sf_style_id_t id);
```

`sf_theme_set_active()` 会重新 `init_styles()` 所有预置样式，再
`lv_obj_report_style_change(NULL)` 触发全局重绘；主题 ID 持久化经 `sf_config_set_theme()`。

## 7. 使用方法

### 7.1 颜色常量

```c
// before（硬编码）
lv_obj_set_style_bg_color(obj, lv_color_hex(0x252540), 0);

// after（主题宏）
lv_obj_set_style_bg_color(obj, SF_COLOR_BG_CARD, 0);
```

### 7.2 字体宏

```c
// before
lv_obj_set_style_text_font(lbl, &lv_font_montserrat_14, 0);

// after
lv_obj_set_style_text_font(lbl, SF_FONT_SM, 0);
```

### 7.3 预置样式

```c
// before
lv_obj_set_style_bg_color(cont, lv_color_hex(0x1a1a2e), 0);
lv_obj_set_style_border_width(cont, 0, 0);
lv_obj_set_style_pad_all(cont, 0, 0);
lv_obj_set_style_radius(cont, 0, 0);

// after
lv_obj_add_style(cont, sf_theme_get_style(SF_STYLE_PAGE), 0);
```
