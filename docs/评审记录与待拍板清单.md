## 三、已核实无问题的部分

以下疑点经核对**不成立**，无需处理：

- **board 引脚宏对齐**：`sf_hal_board.c` 的 `board_pins` 与板 Kconfig 全量匹配（`CONFIG_SF_PIN_BTN_BACK/HOME`、`CONFIG_SF_PIN_I2S_*` 均存在，非 BTN0/BTN1 冲突）。
- **monitor 数据竞争**：disk/mem/tasks 三个数据模块各自持有互斥锁，无跨线程竞争。
- **esp_lvgl_port 锁**：为递归锁，GUI 回调内再 `lvgl_port_lock(0)` 不会死锁；`timeout_ms=0` 语义是无限等待而非不阻塞。
- **LVGL 内存池**：256KB（`CONFIG_LV_MEM_SIZE_KILOBYTES=256`）位于 PSRAM，非早期审计所述的 64KB。
- **依赖方向**：`sf_gui → sf_sys → sf_config`、apps → GUI+HAL，整体健康，无反向依赖。
