# ESP32-S3 Touch LCD 2.8" 引脚分配文档

> **引脚事实来源**：板级引脚已统一收口到 `boards/esp32s3-touch-lcd-2_8/Kconfig`
> （`CONFIG_SF_PIN_*` 选项），由 `components/sf_hal/board/sf_hal_board.c` 收集为
> `sf_board_pins_t`。本文为 GPIO 分配说明与驱动实现状态对照。
> 本文宏名/文件路径均为**当前代码**（`components/sf_hal/`）中的实际引用，旧 `main/LCD_Driver/*` 等路径已随驱动迁入删除。

## 项目概述

- **主控芯片**: ESP32-S3R8 双核处理器，最高 240MHz
- **Flash**: 16MB
- **LCD**: ST7789V (SPI 接口，240×320，RGB565) — **已接入** `sf_hal/display`
- **触摸**: CST328 (I2C 接口) — **已接入** `sf_hal/input`
- **姿态传感器**: QMI8658 六轴陀螺加速度计 (I2C) — 板载硬件，驱动未接入 HAL
- **RTC**: PCF85063 (I2C) — 板载硬件，驱动未接入 HAL
- **音频**: PCM5101 音频解码芯片 + 功放芯片 (I2S) — 板载硬件，驱动未接入 HAL
- **音量调节**: 旋钮 (未定义 GPIO)
- **电池管理**: ME6217C33M5G LDO + 充电管理芯片
- **SD 卡**: Micro SD 卡座 (SDMMC 1-bit 模式) — 板载硬件，驱动未接入 HAL
- **天线**: 贴片陶瓷天线 / IPEX 1 代座子 (通过电阻切换)

> **驱动实现状态**：当前 `sf_hal` 仅启用显示与触摸（`CONFIG_SF_HAL_DISPLAY_ST7789` /
> `CONFIG_SF_HAL_INPUT_TOUCH_CST328`）。IMU/RTC/音频/SD 的 GPIO 已在板 Kconfig 中定义，
> 但对应驱动尚未编写，引脚号仅作预留。

## 一、LCD 显示屏 — ST7789 (SPI)

| 引脚功能 | GPIO | 方向 | 板 Kconfig 选项 |
|---------|------|------|----------------|
| SPI MOSI | **GPIO 45** | 输出 | `CONFIG_SF_PIN_LCD_MOSI` |
| SPI MISO | **-1** (未使用) | — | `CONFIG_SF_PIN_LCD_MISO` |
| SPI SCLK | **GPIO 40** | 输出 | `CONFIG_SF_PIN_LCD_SCLK` |
| LCD CS | **GPIO 42** | 输出 | `CONFIG_SF_PIN_LCD_CS` |
| LCD DC | **GPIO 41** | 输出 | `CONFIG_SF_PIN_LCD_DC` |
| LCD RST | **GPIO 39** | 输出 | `CONFIG_SF_PIN_LCD_RST` |
| 背光 (PWM) | **GPIO 5** | 输出 (LEDC PWM) | `CONFIG_SF_PIN_LCD_BL` |

**SPI 配置**（`CONFIG_SF_HAL_DISPLAY_*`）:
- SPI 主机: `SPI3_HOST`
- 时钟频率: 80 MHz（`CONFIG_SF_HAL_DISPLAY_PIXEL_CLOCK_HZ=80000000`）
- 命令/参数位宽: 8-bit（`CONFIG_SF_HAL_DISPLAY_CMD_BITS` / `PARAM_BITS`）
- 背光有效电平: 高（`CONFIG_SF_HAL_DISPLAY_BL_ON_LEVEL=1`）

**背光 PWM 配置**:
- LEDC 定时器: `LEDC_TIMER_0`
- LEDC 通道: `LEDC_CHANNEL_0`
- PWM 频率: 5 kHz
- PWM 分辨率: 13-bit (最大占空比 8191)

## 十三、备注

1. **I2C 接口注意事项**: 根据板级设计，GPIO 10/11 的通用 I2C 总线仅允许外接 I2C 设备，不可映射为其他功能。
2. **音量调节旋钮**: 硬件层面直接连接到音频功放芯片，软件尚未实现。
3. **充电指示灯**: 连接系统电池时，充电为常亮，充满熄灭（未连接系统电池时状态不定）。
4. **天线切换**: 贴片陶瓷天线与 IPEX 1 代座子之间通过焊接/拆焊电阻选择。
5. **UART 接口**: 默认使用 USB Type-C 对应的 UART0 (GPIO 43 = TX, GPIO 44 = RX) 进行日志打印和烧录。
6. **修改引脚**: 改 `boards/esp32s3-touch-lcd-2_8/Kconfig` 后 `idf.py reconfigure` 生效。
